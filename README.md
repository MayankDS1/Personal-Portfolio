# Taskflow — To-Do List & Task Manager

A responsive task manager built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a modern browser. No build tools are required.

## Features
- Add, edit, delete and complete tasks
- Filter all, active and completed tasks
- High, normal and low priority labels
- Summary counts and clear-completed action
- Saves tasks in browser `localStorage`
- Responsive layout and light/dark theme toggle

## Data note
Tasks are stored only in the current browser on the current device. Clearing browser site data may remove them.
